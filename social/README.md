# social/ — tuagente.uy's own brand, for Instagram

Our posts are made by our own agent, Mr. Wobbles, with the engine's `social`
plugin (`kit/plugins/social/`). This folder is what that agent is given, and
the brand assets around it.

| File | What it is |
|---|---|
| `brand.md` | the identity: audience, voice, slide 1, allowed claims, jobs, pillars, looks, caption formula. It is copied to the agent's `marca/brand.md` (`engine/instances/tuagente/workspace/`); change it here and copy it over |
| `looks/` | one sample slide per look, for reference |
| `logo/kit/` | the logo kit: lockups, wordmark and marks, built by `build.py` |
| `logo/*.png` | the Instagram profile pictures and the mark at 1080 |

The HTML renderer and templates that lived here before the engine (and the
`ig-post` Claude skill that used them) were removed on 2026-09-26: the slides
are generated by the `image` plugin.
