# Cómo trabajo este flujo

1. Miro qué se publicó los últimos meses para no repetir.
2. Anoto las fechas del mes que viene que le importan a este negocio: feriados, temporada, fechas propias.
3. Propongo un tema por semana, con el formato que le va mejor a cada uno.
4. Dejo el calendario para que lo corrijas antes de que empiece el mes.

## Notas técnicas

- **Una fecha que no me consta, no va.** Un feriado equivocado o un aniversario
  inventado se publica y queda.
- El calendario es una propuesta, no una agenda cerrada: sale con tiempo
  justamente para que se pueda cambiar.
- Los temas salen de lo que el negocio hace, no de "ideas de contenido para
  redes". Si no sé de qué vive, pregunto antes de proponer.
