# Los siete tipos de posteo, y los golpes de cada uno

El **formato** (feed, carousel, reel, story) decide el envase: cuántos
caracteres, cuántas slides, dónde corta. El **tipo** decide el argumento: en qué
orden van las ideas para que el posteo cierre.

Un posteo es formato × tipo. Los dos se eligen antes de escribir una palabra.

## Cómo elegir el tipo

Preguntale al material, no al cliente:

- ¿Enseña a hacer algo? → **educational**
- ¿Hay un cliente real con un resultado? → **social-proof**
- ¿Se está vendiendo algo puntual? → **offer**
- ¿Es la cocina del negocio? → **behind-the-scenes**
- ¿Discute algo que "todo el mundo hace"? → **opinion**
- ¿Cambió algo que el seguidor necesita saber? → **announcement**
- ¿Es la pregunta que le hacen quince veces por semana? → **faq**

## Los golpes

### educational — enseña una cosa, no cinco
1. El problema, en la lengua del que lo sufre
2. Por qué pasa (una sola causa)
3. Los pasos, numerados y accionables hoy
4. Cómo se ve cuando salió bien
5. Un pedido: guardalo

**Formato natural:** carousel. Un paso por slide.
**Se rompe cuando:** enseña cinco cosas a medias en vez de una entera.

### social-proof — un caso, con número
1. Quién era y qué le pasaba (sin nombre si no hay permiso)
2. Qué se hizo, concreto
3. El resultado, con número o con plazo
4. Qué quiere decir eso para el que lee

**Formato natural:** carousel o feed.
**Se rompe cuando:** el número es inventado o el testimonio es genérico
("¡excelente atención!" no prueba nada).

### offer — qué es, para quién, y qué no es
1. Para quién es, dicho de una manera que se reconozca
2. Qué incluye
3. **Qué NO incluye** — este golpe es el que la hace creíble
4. Precio, o cómo se cotiza
5. Un pedido: escribinos

**Formato natural:** feed o carousel corto.
**Se rompe cuando:** promete todo a todos y se salta el punto 3.

### behind-the-scenes — la cocina
1. Una escena concreta, con hora y lugar
2. Qué cuesta o qué salió mal
3. Qué se hace igual, y por qué
4. Sin moraleja: se termina en la escena

**Formato natural:** reel o story.
**Se rompe cuando:** le pega una moraleja de LinkedIn al final.

### opinion — una postura que se pueda discutir
1. Lo que "todo el mundo" hace
2. Por qué no funciona
3. Qué hacemos nosotros en su lugar
4. Invitar a la discusión de verdad

**Formato natural:** feed.
**Se rompe cuando:** la postura es tibia. Si nadie puede estar en desacuerdo, no
es una opinión, es un lugar común.

### announcement — algo cambió
1. Qué cambió
2. Desde cuándo
3. Qué tiene que hacer el que lee
4. Dónde pregunta si no entendió

**Formato natural:** feed + story.
**Se rompe cuando:** celebra el cambio sin decir qué tiene que hacer el otro.

### faq — la pregunta de todas las semanas
1. La pregunta tal cual la hacen, con sus palabras
2. La respuesta corta, en la primera línea
3. El matiz, o el "depende"
4. Qué hacer ahora

**Formato natural:** feed o carousel de 3.
**Se rompe cuando:** contesta lo que la empresa quiere contestar y no lo que
preguntaron.

## Qué tipo entra en qué formato

| | feed | carousel | reel | story |
|---|---|---|---|---|
| educational | ok | **ideal** | ok | no |
| social-proof | **ideal** | ideal | ok | ok |
| offer | **ideal** | ok | ok | ok |
| behind-the-scenes | ok | no | **ideal** | **ideal** |
| opinion | **ideal** | ok | ok | no |
| announcement | **ideal** | no | ok | **ideal** |
| faq | ideal | **ideal** | ok | ok |

"no" no quiere decir prohibido: quiere decir que si vas por ahí, tenés que saber
por qué.
