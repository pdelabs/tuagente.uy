# tuagente.uy

Landing page for **tuagente** — we set up autonomous AI agents inside LATAM
companies. A product by [pdelabs](https://www.pdelabs.com).

Next.js 14 (App Router) + Tailwind. Deploy on Vercel.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Placeholders to replace before going live: contact number/email, the hype
stats, and the social-proof logos/quotes.
